# MyColorfulSpiral
This is a fun Intermediate Graphics Program using Turtle
This repository shows two versions of the same spiral program, the original hand-written version, and a second version enhanced with Claude Code that adds random color changes and a while loop. Then a line noting that Claude Code's first draft included some features, like try-except error handling, that were too advanced for the intermediate class this was written for, so it was simplified back down to match that level.
